SAMP 采样功能说明

采样定义、自动采样、结果查询与 SQLite 数据组织说明

目录1. 功能概览2. 数据存储3. 采样定义4. 自动采样5. 采样查询6. API 接口7. 启动与运维8. 常见问题

1. 功能概览

SAMP 用采样定义描述“从哪个 SQLite 数据库的哪张表读取哪些字段、按什么周期保存”，后台按定义执行采样，并提供 Web 查询和 CSV 导出。

① 定义选择源库、源表、字段和周期
② 读取按定义访问真实源表
③ 保存写入采样点年度结果库
④ 查询按时间和字段查看结果
  • Web 页面包含采样定义、运行监控、采样查询三个区域。
  • 源表由采样定义指定，程序不依赖固定的 source_rows 表。
  • 页面和接口不暴露旧版 EMS 的 app、ctx 维度。
  • 采样点名、源表名和字段名支持字母、数字、下划线及中文。

2. 数据存储

默认 SQLite 根目录为：

D:\codex\sqldb\realtime\samp
文件用途结构
samp_define.db采样定义只有一张 samp_define 表
samp_采样点名_年份.db采样结果每个库只有一张同名表，例如 samp_电表A_2026
用户指定的源库实时源数据由定义中的 source_database 和 source_table 决定
结果库直接放在 SQLite 根目录。查询跨年度时，服务会按涉及的年份读取多个结果库并合并排序。

定义表主要字段

字段说明
samp_name采样点名，唯一，同时参与结果库和结果表命名。
source_database源 SQLite 文件的绝对或相对路径。
source_table源数据库中的真实表名。
field_name逗号分隔的采样字段列表。
samp_time采样周期，单位为秒；0 表示只手动采样。
filter_value可选过滤条件，如 status=1 and quality=0。
enabled是否启用自动采样。

3. 采样定义

  1. 打开 Web 首页，进入“采样定义”。
  2. 填写采样点名和源数据库路径。
  3. 点击“读取表”，或直接填写源表名。
  4. 点击“读取字段和预览”，确认源表结构和数据。
  5. 选择要采样的业务字段，设置周期和过滤条件。
  6. 点击“保存定义”。

定义页可执行操作

操作行为
新建创建新的采样定义。
编辑重新读取源表后修改字段、周期、过滤条件或启停状态。
立即采样绕过周期立即读取一次源表并写入结果库。
启用/停用控制后台自动采样；停用不删除历史结果。
删除删除定义记录，不自动删除已有结果库。
源表必须已经存在，选择的字段也必须属于该表。内部行标识字段 row_key 用于保存结果行定位，不作为页面业务采样字段。

4. 自动采样

Web 服务启动后会运行后台采样循环。循环每秒检查启用的采样定义，周期大于 0 且到达触发时间时执行一次。

周期设置行为
大于 0按秒周期自动采样，例如 60 表示每 60 秒一次。
等于 0不自动执行，只能使用“立即采样”或 POST 接口。
停用跳过自动采样，但保留定义和历史结果。

结果写入

每次采样按当前 UTC 年份选择结果库，写入 sample_time、row_key 以及定义字段。相同采样时间和行标识再次写入时会替换原行。

运行监控页显示定义数量、启用数量、自动采样数量、结果年份和最近结果文件时间。

5. 采样查询

  1. 进入“采样查询”，选择采样点。
  2. 输入开始和结束时间。
  3. 选择需要显示的字段。
  4. 点击“查询”。

查询结果包含采样时间、源表行标识和所选字段。页面显示结果表，并提供数值字段概览和 CSV 导出。查询范围可以跨年，系统会合并对应年份的结果表。页面提供“最近 1 小时”“今天”“最近 24 小时”快捷范围，结果按 500 行分页显示，可用上一页、下一页浏览，CSV 按当前页导出。

时间输入使用浏览器本地时间，接口参数使用 Unix 时间戳（秒）。

6. API 接口

FastAPI 自动文档地址为 /docs。主要接口如下：

方法和路径用途
GET /api/definitions获取全部采样定义。
POST /api/definitions创建采样定义。
PUT /api/definitions/{id}更新采样定义。
DELETE /api/definitions/{id}删除采样定义。
POST /api/definitions/{id}/enable?enabled=true|false启用或停用定义。
GET /api/definitions/{id}/runtime读取单个采样点运行状态。
POST /api/sample/{id}立即执行一次采样。
POST /api/sample/all并行执行全部已启用采样定义。
GET /api/query/{id}?start=&end=&fields=&limit=&offset=按时间、字段和分页参数查询采样结果；返回 total_rows、limit、offset。
GET /api/source/tables?source_database=读取源库中的表名。
GET /api/source/inspect?source_database=&source_table=读取源表字段和预览数据。
GET /api/status读取服务总体状态。

创建定义示例

POST /api/definitions
Content-Type: application/json

{
  "name": "电表A",
  "source_database": "D:/data/realtime.db",
  "source_table": "meter",
  "fields": ["voltage", "current"],
  "interval_seconds": 60,
  "filter": "status=1",
  "enabled": true
}

7. 启动与运维

启动 Web

cd D:\codex\samp
python -m samp --host 127.0.0.1 --port 8877
# 默认使用 http://127.0.0.1:8877

如端口被占用，可以指定端口，例如：

python -m samp --host 127.0.0.1 --port 8877

启动独立自动采样进程

python -m samp.sampler

修改 SQLite 根目录

$env:SAMP_SQLITE_DIR="D:\data\samp"
python -m samp

验证服务

Invoke-WebRequest http://127.0.0.1:8877/api/health
Invoke-WebRequest http://127.0.0.1:8877/api/status

8. 常见问题

读取源表失败

检查数据库路径是否存在、当前进程是否有读取权限、源表名是否拼写正确。可在页面点击“读取字段和预览”查看具体错误。

采样写入 0 行

确认源表有数据，并检查过滤条件是否把所有行排除了。没有过滤条件时，服务会读取源表全部行。

查询没有结果

确认查询时间覆盖实际采样时间，并检查采样点名是否对应结果库。可以先使用“立即采样”生成一条当前结果，再查询当前时间附近的范围。

删除定义后结果是否还在

删除操作只删除 samp_define 中的定义记录，不删除已有的年度结果库；如需清理结果库，应先确认文件和采样点范围后手工处理。
