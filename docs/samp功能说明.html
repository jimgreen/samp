SAMP 采样功能说明

采样定义、自动采样、结果查询与 SQLite 数据组织说明

目录1. 功能概览2. 数据存储3. 采样定义4. 自动采样5. 采样查询6. API 接口7. 启动与运维8. 常见问题

1. 功能概览

SAMP 用采样定义描述“从哪个 SQLite 数据库的哪张表读取哪些字段、按什么周期保存”，后台按定义执行采样，并提供 Web 查询和 CSV 导出。

① 定义选择源库、源表、字段和周期
② 读取按定义访问真实源表
③ 保存写入采样点年度结果库
④ 查询按时间和字段查看结果
  • Web 界面包含四个统一指挥舱页面：/dashboard 大屏主画面、/definitions 采样定义、/runtime 运行监控（含 /storage 快捷入口）、/query 采样查询。
  • 源表由采样定义指定，支持周期采样、定点采样（按时/日/周/月）与标志位/API 触发采样，程序不依赖固定的 source_rows 表。
  • 采样点名、源表名和字段名支持字母、数字、下划线及中文，支持全表 * 字段自动跟随源表加列。

2. 数据存储

默认工作根目录为（可通过 SAMP_ROOT_DIR 或 --root-dir 修改，业务定义中统一保存相对路径）：

D:\codex\workspace
文件用途结构
samp_define.db采样定义一张 samp_define 业务表
samp_采样点名_年份.db采样结果每个库一张同名业务表，例如 samp_电表A_2026
用户指定的源库实时源数据由定义中的 source_database 和 source_table 决定
结果库直接放在 SQLite 根目录。查询跨年度时，服务会按涉及的年份读取多个结果库并合并排序。

定义库和结果库内置 RTDB 结构定义。SAMP 建表、补列时会同步更新，并在启动时为历史库补登记。支持原生 SQLite 布局的 RTDB 可以直接打开这些 .db 文件并只读查询。新增字段在首次采样时写入当年结果表，较早的记录在该字段上显示为空。

定义表主要字段

字段说明
samp_name采样点名，唯一，同时参与结果库和结果表命名。
source_database源 SQLite 文件的绝对或相对路径。
source_table源数据库中的真实表名。
field_name逗号分隔的采样字段列表。
samp_time采样周期，单位为秒；0 表示只手动采样。
filter_value可选过滤条件，如 status=1 and quality=0。
enabled是否启用自动采样。

3. 采样定义

  1. 打开 Web 首页，进入“采样定义”。
  2. 填写采样点名和源数据库路径。
  3. 点击“读取表”，或直接填写源表名。
  4. 点击“读取字段和预览”，确认源表结构和数据。
  5. 选择要采样的业务字段，设置周期和过滤条件。
  6. 点击“保存定义”。

定义页可执行操作

操作行为
新建创建新的采样定义。
编辑重新读取源表后修改字段、周期、过滤条件或启停状态。
立即采样绕过周期立即读取一次源表并写入结果库。
启用/停用控制后台自动采样；停用不删除历史结果。
删除删除定义记录，不自动删除已有结果库。
源表必须已经存在，选择的字段也必须属于该表。内部行标识字段 row_key 用于保存结果行定位，不作为页面业务采样字段。

4. 自动采样

Web 服务启动后会运行后台采样循环。循环每秒检查启用的采样定义，周期大于 0 且到达触发时间时执行一次。

周期设置行为
大于 0按秒周期自动采样，例如 60 表示每 60 秒一次。
等于 0不自动执行，只能使用“立即采样”或 POST 接口。
停用跳过自动采样，但保留定义和历史结果。

结果写入

每次采样按当前 UTC 年份选择结果库，写入 sample_time、row_key 以及定义字段。相同采样时间和行标识再次写入时会替换原行。

运行监控页显示定义数量、启用数量、自动采样数量、结果年份和最近结果文件时间。

5. 采样查询

  1. 进入“采样查询”，选择采样点。
  2. 输入开始和结束时间。
  3. 选择需要显示的字段。
  4. 点击“查询”。

查询结果包含采样时间、源表行标识和所选字段。页面上半区提供离线交互式 Canvas 2D 多曲线趋势图（支持同轴 / 归一化 / 分轨堆叠、滚轮缩放、拖拽平移、Shift 框选放大、上下限参考线、十字准星读数、图例开关与 PNG 导出），下半区展示首两列左冻结的高密度分页数据表，支持按 row_key 筛选、单时刻快照对比 Diff、降采样聚合（均值/原始/最大/最小/最新）、时间升降序切换、实时自动刷新与全量流式 CSV 导出。全站内置 16 套官方主题预设、中 / 英 / 俄三语实时切换、左侧悬浮/内嵌双模式导航与全屏切换。

时间输入使用浏览器本地时间，接口参数使用 Unix 时间戳（秒）。

6. API 接口

FastAPI 自动文档地址为 /docs。主要接口如下：

方法和路径用途
GET /api/definitions获取全部采样定义。
POST /api/definitions创建采样定义。
PUT /api/definitions/{id}更新采样定义。
DELETE /api/definitions/{id}删除采样定义。
POST /api/definitions/{id}/items向已定义的采样点追加一条采集项（同库独立业务表）。
PUT /api/definitions/{id}/items/{item_id}修改采样点内指定采集项的源库/源表/目标表/字段/过滤。
DELETE /api/definitions/{id}/items/{item_id}移除采样点内指定采集项（至少保留一条）。
POST /api/definitions/{id}/enable?enabled=true|false启用或停用定义。
POST /api/definitions/batch-enable批量启用或停用采样定义。
GET /api/definitions/{id}/runtime读取单个采样点运行状态与调度快照。
POST /api/sample/{id}立即执行一次采样（一库多表同事务写入）。
POST /api/sample/all并行执行全部已启用采样定义。
GET /api/query/{id}?start=&end=&item_id=&fields=&row_keys=&order=&limit=&offset=按时间、采集项、字段、row_key、排序和分页参数查询采样结果。
GET /api/query/{id}/keys?start=&end=&item_id=获取时间范围内的去重 row_key 列表。
GET /api/query/{id}/series?start=&end=&item_id=&fields=&row_keys=&agg=&bucket_seconds=获取趋势图聚合/降采样序列与分组统计。
GET /api/query/{id}/export?start=&end=&item_id=&fields=&row_keys=&order=全量流式导出 UTF-8 CSV。
GET /api/config读取服务配置、根目录、默认源库、已有目标目录与调度状态。
GET /api/source/databases扫描工作根目录下可用源 SQLite 数据库（相对路径）。
GET /api/source/tables?source_database=读取源库中的表名。
GET /api/source/inspect?source_database=&source_table=&filter=读取源表字段类型、命中计数和预览数据。
GET /api/runtime/logs?limit=&status=读取最近采样执行与错误日志。
GET /api/storage/databases / DELETE /api/storage/databases/{path}查看全部结果库（含自定义目录与多表统计）、识别孤儿库并安全删除。
GET /api/status一次性读取服务总览、全量单点运行态与最近日志。

  "name": "变电站A",
  "target_dir": "archive/station",

  "enabled": true,
  "items": [

      "source_database": "realtime/substation.db",
      "source_table": "meter",
      "target_table": "",
      "fields": ["voltage", "current"],

    },
    {
      "source_database": "realtime/substation.db",
      "source_table": "inverter",
      "target_table": "inverter",
      "fields": ["kw", "temp"],
      "filter": ""
    }
  ]
}

7. 启动与运维

启动 Web

cd D:\codex\samp
python -m samp --host 127.0.0.1 --port 8877
# 默认使用 http://127.0.0.1:8877

如端口被占用，可以指定端口，例如：

python -m samp --host 127.0.0.1 --port 8877

启动独立自动采样进程

python -m samp.sampler

修改 SQLite 根目录

$env:SAMP_SQLITE_DIR="D:\data\samp"
python -m samp

验证服务

Invoke-WebRequest http://127.0.0.1:8877/api/health
Invoke-WebRequest http://127.0.0.1:8877/api/status

8. 常见问题

读取源表失败

检查数据库路径是否存在、当前进程是否有读取权限、源表名是否拼写正确。可在页面点击“读取字段和预览”查看具体错误。

采样写入 0 行

确认源表有数据，并检查过滤条件是否把所有行排除了。没有过滤条件时，服务会读取源表全部行。

查询没有结果

确认查询时间覆盖实际采样时间，并检查采样点名是否对应结果库。可以先使用“立即采样”生成一条当前结果，再查询当前时间附近的范围。

删除定义后结果是否还在

删除操作只删除 samp_define 中的定义记录，不删除已有的年度结果库；如需清理结果库，应先确认文件和采样点范围后手工处理。
